# Looker Authentication & MCP Toolbox Integration

This skill provides comprehensive instructions for configuring credentials, environment variables, and the local **MCP Toolbox for Databases (`@toolbox-sdk/server`)** to enable AI agents (Claude Desktop, Cursor, VS Code, Antigravity) to safely interact with a Looker instance.

Using the local MCP Toolbox is the official standard for allowing AI agents to query metadata, explore dimensions/measures, and develop LookML models within your local system context without remote credential forwarding.

---

## 1. Looker Credentials Reference

To connect to your Looker server, obtain an API3 Client ID and Client Secret from your Looker Admin Console (**Admin > Users > Edit User > API3 Keys**):

- **Base URL**: `https://<YOUR_LOOKER_INSTANCE>.looker.app` (e.g., `https://analytics.example.com` or port `443`/`19999`)
- **Client ID**: `<YOUR_LOOKER_CLIENT_ID>`
- **Client Secret**: `<YOUR_LOOKER_CLIENT_SECRET>`

---

## 2. Environment Variables Mapping

Different client layers require specific environment variable prefixes. Ensure the appropriate variables are exported in your active shell or `.env` / `.envrc`:

| Client / Tool | Required Environment Variables |
| :--- | :--- |
| **Looker Python SDK** | `LOOKERSDK_BASE_URL`, `LOOKERSDK_CLIENT_ID`, `LOOKERSDK_CLIENT_SECRET` |
| **MCP Toolbox for Databases** | `LOOKER_BASE_URL`, `LOOKER_CLIENT_ID`, `LOOKER_CLIENT_SECRET` |

---

## 3. Local MCP Configuration

To integrate the Looker MCP tools directly into your IDE, add the following server configuration block to your `mcp_config.json`:

```json
{
  "mcpServers": {
    "looker-toolbox": {
      "command": "npx",
      "args": ["-y", "@toolbox-sdk/server", "--prebuilt", "looker,looker-dev", "--stdio"],
      "env": {
        "LOOKER_BASE_URL": "https://<YOUR_LOOKER_INSTANCE>.looker.app",
        "LOOKER_CLIENT_ID": "<YOUR_LOOKER_CLIENT_ID>",
        "LOOKER_CLIENT_SECRET": "<YOUR_LOOKER_CLIENT_SECRET>"
      }
    }
  }
}
```

## 4. Key MCP Tools Reference

The Looker toolbox exposes **45 prebuilt tools** divided into two primary areas:

### A. LookML Development (`looker-dev` prebuilt)
Use these tools to write, modify, branch, and validate LookML models:
- **`dev_mode`**: Toggle Looker session between Dev and Prod (`{"dev_mode": true}`).
- **`get_projects`**: List all available projects.
- **`get_git_branch` / `create_git_branch` / `switch_git_branch`**: Branching operations.
- **`get_project_files` / `get_project_file`**: Read directory structure and files.
- **`create_project_file` / `update_project_file`**: Write and modify LookML code.
- **`validate_project`**: Compile and run the LookML validator.
- **`create_view_from_table`**: Auto-generate a boilerplate LookML view file from a physical BigQuery schema.

### B. Business Intelligence & Querying (`looker` prebuilt)
Use these tools to fetch data and inspect the semantic layout:
- **`get_models` / `get_explores`**: Discover the active semantic layer.
- **`get_dimensions` / `get_measures`**: Inspect fields within an explore.
- **`query`**: Run a structured Looker semantic query.
- **`query_sql`**: Retrieve the compiled SQL generated by a Looker query.
- **`run_dashboard` / `run_look`**: Retrieve data from existing reports.
